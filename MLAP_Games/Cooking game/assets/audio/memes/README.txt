Drop your own short clips (.ogg, .wav or .mp3, ideally 1-4 seconds) into these folders.
One is picked at random when the event happens. Empty folders = silence.

start   - game begins
grab    - picking up a vegetable
drop    - vegetable lands in the pot
soup_3  - customer gives 3 stars (celebration)
soup_2  - 2 stars (okay-ish)
soup_1  - 1 star (disappointed)
oops    - stirring off the line / wrong way
end     - time is up

Only use clips you have the right to use.
